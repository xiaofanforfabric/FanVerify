# FanVerify 开发者服务协议

更新日期：2026-09-05  
生效日期：2026-09-05

FanVerify（以下简称"本服务"）由**个人开发者**独立开发，借由**商洛市商州区博誉办公设备经营部**主体上线与运营。在您申请接入本服务 OpenAPI 成为开发者（以下简称"您"）之前，请您仔细阅读并充分理解本协议的全部内容。**您提交开发者申请即视为您已阅读并同意接受本协议的约束。**

## 一、开发者资质要求

1. 您申请本服务 API 开发者令牌（devaccesstoken）时，您的 FanVerify 账号必须已达到**二级验证**（即已绑定手机号）。
2. 您申请成功后，您的 FanVerify 账号**无法通过解绑手机号进行降级**（仅可更换绑定手机号）。

## 二、接入与使用规范

1. **一个业务对应一台服务器**；如使用多台服务器，须统一通过**同一出口 IP** 对外访问。
2. **一个业务仅允许使用一个 API 密钥**（devaccesstoken）。
3. **严禁混用**：禁止多业务共用一个密钥、或一个业务使用他人密钥等行为。一经发现，我们有权**取消您的开发者资格**。

## 三、内容合规

1. 您接入本服务所提供或关联的服务，**不得涉及任何法律明确禁止的内容**（包括但不限于色情、赌博、毒品等"黄赌毒"类服务）。
2. 若您的业务内容违反法律法规，我们有权**立即停止服务并取消您的开发者资格**，且不承担由此产生的任何责任。

## 四、禁止二次分发

1. 您**不得**通过代理、中转或任何其他方式对本服务 API 进行**二次分发**（无论是否收费）。

## 五、竞品渠道与品牌使用限制

1. 为避免引发不必要的误解、纠纷或关联联想，开发者**不得**在本服务**竞品组织或机构**（包括但不限于其官方及非官方社群、交流群、论坛、直播间等）中，以任何形式**展示、宣传或提及**本服务、本服务标识（包括但不限于名称、Logo、域名、验证链接与二维码等）。
2. 除本条第 1 款所述竞品渠道外，开发者可在其他公开场合（如博客、视频网站、社交媒体等）**正常评价或宣传本服务**，但不得冒用本服务官方名义，亦不得作虚假或贬损性宣传。
3. 开发者自身产品的合法宣传**不受本条限制**；若在其中提及或展示本服务，仍须遵守本条第 1 款之规定。

## 六、密钥管理

1. 您申请获得的密钥（devaccesstoken）**不得以出租、出借、转让或任何其他方式**提供给他人使用。
2. 因您保管不善导致密钥泄露、被他人使用所造成的后果，由您自行承担。

## 七、服务可用性要求

1. 为避免"空气服务器"滥用，您申请密钥时，您拟接入的服务需**至少连续在线一天**且可正常访问。
2. 我们保留对您服务在线状态进行核实与抽查的权利。

## 八、免责声明

1. 本项目为**个人开发**，不承诺任何 SLA（服务等级协议）。本服务适用于个人网站、个人类项目等场景，**不适合对稳定性有高要求的企业级场景**。
2. 开发者可能因**精力、资金**等客观原因导致服务暂停或停止，**不保证服务的永久可用性**。对于任何服务异常造成的损失，我们不承担任何责任，请您自行做好容灾与备份。
3. 我们**仅提供鉴权服务**。如开发者与其服务用户之间发生纠纷，双方应当友好协商解决，我们不承担任何责任。

## 九、违约处理

1. 违反本协议任一约定（包括但不限于密钥混用、二次分发、出租转让密钥、接入违规内容等），我们有权视情节采取警告、限制接口、终止服务、取消开发者资格等措施，且无需为此承担任何责任。

## 十、协议变更与终止

1. 我们可能适时修订本协议。修订后的协议在本页面公布，并自公布之日起生效。
2. 我们可能因运营需要调整或终止开发者接入服务，并将在合理范围内提前通知。
