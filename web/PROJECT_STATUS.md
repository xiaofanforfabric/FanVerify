## 🚀 如何运行

### 方式一：使用批处理脚本（推荐）
```bash
# 双击运行
GO/web/start-dev.bat
```

### 方式二：命令行
```bash
cd GO/web
npm install  # 首次运行需要安装依赖
npm run dev
```

### 方式三：Visual Studio Code
1. 打开 `GO/web` 目录
2. 终端运行 `npm run dev`
3. 访问 http://localhost:5173

## 📦 构建生产版本

```bash
cd GO/web
npm run build
```

构建产物将输出到 `dist/` 目录。

## 🔗 集成到 Go 后端

可以在 `GO/main.go` 中添加静态文件服务：

```go
// 在 main 函数中添加
fs := http.FileServer(http.Dir("./web/dist"))
mux.Handle("/", http.StripPrefix("/", fs))
```

然后访问 http://localhost:8888 即可查看官网。
